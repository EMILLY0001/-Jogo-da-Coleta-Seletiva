# ♻️ Jogo da Coleta Seletiva

## Descrição do Projeto

O Jogo da Coleta Seletiva é uma aplicação educativa que ensina a separação correta dos resíduos recicláveis de forma divertida e interativa. O jogador deve arrastar cada material para a lixeira correspondente, acumulando pontos e aprendendo sobre reciclagem.

---

## Objetivo do Projeto

Conscientizar sobre a importância da coleta seletiva e da destinação correta dos resíduos para a preservação do meio ambiente e para a construção de cidades mais sustentáveis.

---

✅ Sistema de arrastar e soltar (Drag and Drop)

✅ Feedback de acertos e erros

✅ Mensagem de vitória

✅ Interface educativa

✅ Layout responsivo

---

## Como Executar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html`.
3. Arraste os resíduos para as lixeiras corretas.
4. Acumule pontos e complete o desafio.
